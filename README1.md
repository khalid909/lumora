# Lumora — متجر إلكتروني عصري (عربي • Français • English)

متجر جاهز يعمل مباشرة على **GitHub Pages** بدون خادم وبدون أي أدوات بناء.

## المميزات

- **3 لغات** (العربية RTL، الفرنسية، الإنجليزية) مع تبديل فوري وحفظ الاختيار.
- **وضع داكن/فاتح** تلقائي حسب جهاز الزبون، مع انتقال سلس (View Transitions API).
- **بحث ذكي**: يتجاهل التشكيل والهمزات، يتحمّل الأخطاء الإملائية، يبحث بالعربية والفرنسية والإنجليزية معًا، **وبحث صوتي** (Web Speech API)، واختصار `/`.
- فلاتر: الفئات، أقصى سعر، ترتيب (الأكثر مبيعًا، الأحدث، أكبر خصم، السعر، التقييم)، المفضلة.
- بطاقات منتجات ثلاثية الأبعاد (Tilt)، حركات ظهور عند التمرير، نافذة تفاصيل المنتج مع رابط مباشر ومشاركة.
- **سلة ذكية**: شريط التوصيل المجاني، أكواد خصم، حفظ تلقائي، حدود المخزون.
- **إتمام الطلب** بالدفع عند الاستلام + إرسال الطلب إلى **واتساب** + احتفال Confetti 🎉.
- **PWA**: قابل للتثبيت كتطبيق ويعمل بدون إنترنت (Service Worker).
- SEO (JSON-LD)، وصولية (لوحة المفاتيح، قارئات الشاشة، تقليل الحركة)، وأداء عالٍ بدون أي مكتبات خارجية.
- **لوحة تحكم**: إضافة/حذف منتجات، عرض الطلبات، تصدير/استيراد JSON، تصدير الطلبات CSV.

## التشغيل على جهازك

افتح `index.html` مباشرة بالنقر المزدوج، أو الأفضل (لتجربة PWA):

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## رفعه على GitHub ونشره (خطوة بخطوة)

### الطريقة 1: من الموقع (بدون أوامر)

1. أنشئ حسابًا على [github.com](https://github.com) إن لم يكن لديك.
2. اضغط **+** (أعلى اليمين) ← **New repository**.
3. اكتب اسمًا مثل `my-store` ← اختر **Public** ← **Create repository**.
4. اضغط **uploading an existing file**.
5. فكّ ضغط ملف ZIP، ثم **اسحب محتويات المجلد** (`index.html` و`css` و`js` و`sw.js` …) إلى الصفحة.
   ⚠️ يجب أن يكون `index.html` في الجذر مباشرة، لا داخل مجلد إضافي.
6. اضغط **Commit changes**.
7. اذهب إلى **Settings ← Pages**. تحت **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** وبجانبه **/(root)** ← **Save**
8. انتظر دقيقة تقريبًا، فيظهر رابط متجرك:
   `https://USERNAME.github.io/my-store/`

### الطريقة 2: بالأوامر (Git)

```bash
cd lumora-store
git init
git add .
git commit -m "Initial store"
git branch -M main
git remote add origin https://github.com/USERNAME/my-store.git
git push -u origin main
```

ثم فعّل **Pages** كما في الخطوة 7 أعلاه.

> لتحديث المتجر لاحقًا: عدّل الملفات ثم `git add . && git commit -m "update" && git push`
> (أو ارفع الملفات المعدّلة من الموقع). يتحدّث الموقع خلال دقيقة.

### ربط دومين خاص (اختياري)
Settings ← Pages ← **Custom domain**، ثم أضف سجل DNS من نوع CNAME يشير إلى `USERNAME.github.io`.

## التخصيص

| ما تريد تغييره | الملف |
|---|---|
| اسم المتجر، العملة، رقم واتساب، التوصيل، أكواد الخصم، كلمة سر اللوحة | `js/config.js` |
| المنتجات الافتراضية والصور | `js/data.js` |
| النصوص والترجمات | `js/i18n.js` |
| الألوان (`--p` و`--p2` و`--grad`) والخطوط | `css/style.css` (أعلى الملف) |

**استقبال الطلبات على واتساب:** ضع رقمك في `whatsapp` بصيغة دولية بدون `+` (مثال: `213550000000`).
عند تأكيد الزبون للطلب تفتح رسالة جاهزة بتفاصيل الطلب.

**صور المنتجات:** ارفعها داخل مجلد `img/` في المستودع، ثم ضع `img: 'img/اسم.jpg'` في المنتج (أو من لوحة التحكم).

**لوحة التحكم:** زر «لوحة التحكم» أسفل الصفحة. كلمة المرور الافتراضية `admin123` — **غيّرها في `config.js`**.

## ⚠️ حدود مهمة (اقرأها)

- المنتجات والطلبات والسلة تُحفظ في **متصفح الزبون** (localStorage). لهذا:
  - ما تضيفه من لوحة التحكم **يظهر في متصفحك أنت فقط**. لنشره للجميع، صدّر `products.json` وانسخ محتواه إلى `js/data.js`، أو اربط قاعدة بيانات.
  - كلمة مرور اللوحة حماية شكلية فقط (الكود مكشوف). لا تعتمد عليها في أمور حساسة.
  - الطلبات تصلك فعليًا عبر **واتساب** أو عبر `orderEndpoint` (مثل Formspree أو Make).
- لا يوجد دفع إلكتروني بالبطاقة في هذه النسخة (الدفع عند الاستلام فقط).

## الخطوة التالية لمتجر احترافي كامل

1. **قاعدة بيانات ومصادقة**: Supabase أو Firebase (منتجات وطلبات ومخزون مشتركة بين كل الزبائن + دخول آمن للمدير).
2. **دفع إلكتروني**: Stripe أو PayPal أو بوابة دفع محلية.
3. **إشعارات الطلبات**: بريد أو Telegram عبر Make/n8n.
4. **تتبّع الزوار**: Plausible أو Google Analytics، وبكسل فيسبوك إن كنت تعلن هناك.

يمكنني تطوير أي نقطة منها معك لاحقًا.
